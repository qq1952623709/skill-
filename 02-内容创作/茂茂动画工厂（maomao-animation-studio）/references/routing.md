# 工具路由与能力预检

执行时读取当前会话中选中技能的 SKILL.md 和其要求的参考文件。先按技能目录表定位，缺失再搜索用户技能目录及插件目录；不永久绑定插件版本路径。

第一次实际操作 ChatCut 时先确认宿主：hosted `chatcut` 连接器须读取 `chatcut:chatcut-plugin-basics`；`chatcut_desktop*` 走桌面自身指令。不要把不同宿主的工具名称、参数和资源标识混用。

## 子技能与交接

| 环节 | 使用能力 | 融合时的处理 |
|---|---|---|
| 目标、预算、独立审计 | ai-master | 保留方向纠偏、先小样、证据晋级和独立终审 |
| 长小说改编、多集结构 | novel-outline | 长篇才进入完整改编流程；一句话动画直接编写原创故事和单集底稿 |
| 角色定位和形象 | novel-characters | 取人物性格、外观、音色和参考图方法；原创补充标为创作，不伪造原文引文 |
| 场景、道具 | novel-art | 固定场景锚点、光照状态、道具尺寸和变体 |
| 剧本对白 | novel-script | 采用动作与台词分开、稳定角色 ID、时长预算；单集独立动画不强制连载悬念 |
| 分镜 | novel-storyboard | 保留节拍认领、关键帧、运镜、台词对账和生成批次；H3 专用提示词不能直接喂其他模型 |
| 参考图生成 | imagegen | 使用真实出图工具，检查角色和场景一致性 |
| 素材进入工程 | chatcut:asset-import、当前 ChatCut host 指令 | 本地路径不是云资产 ID；按实际导入工具转成资产，保存映射 |
| 动画生成 | chatcut:video-gen | 读取当前模型参考，再写实际提示词和参数；生成完成后仍需入时间线 |
| 配音、口型和声音同步 | chatcut:voice 及其 video-sync 参考 | 使用当前官方音色或已授权音色；预设由总经理在授权范围内选；克隆另核授权 |
| 音乐 | chatcut:music | 按场景情绪与台词留白选音乐；不让模型歌词意外盖过对白 |
| 剪辑 | 当前 ChatCut 时间线工具 | 确认秒、毫秒、帧的单位，使用实际工程帧率；不套用口播删停顿规则破坏动画表演 |
| 检查、导出 | chatcut:verification、chatcut:export | hosted 和 desktop 路由服从当前宿主；必须查看合成后的画面与实际音频 |

复用 novel 系列脚本时必须遵守其当前 schema，运行相应 validate。不把本技能的简化清单冒充这些脚本的兼容 JSON。它们有些门只适合连载，单集原创可采用本技能自有清单和人工审查，不伪造源脚本通过，也不为过门加无关剧情。

## 真正执行前检查

确认本次会话能调用：读取/创建目标工程、素材导入、图像生成、视频生成及跟踪、音频生成、时间线编辑及预览、最终导出及跟踪、独立审片。区分“技能文件存在”“工具可调用”“账号可用”“实际成功”四种状态。不要为探测会员资格发付费生成请求。

收费制作前确认独立审片路线满足当前 总经理协议：不同产品线审查方的实际身份、最小数据外传授权、内容寻址副本和权限边界，并确认能检查动态画面与试听声音。方向审查和成品审查分别留证。缺少正式审片能力时先完成免费规划，明确缺口；不能先把制作预算花完，再发现没有合格审片入口。

运行 novel 系列校验脚本前检查 Node.js。若终端 PATH 没有 node，在 Codex 桌面调用工作区依赖查询，使用返回的 Node.js 绝对路径；不把 PATH 缺项误报成技能损坏，也不未经需要重装运行时。脚本实际执行的命令和结果留证。

ChatCut 是默认工程入口，MiniMax 是可选生成模型。只在当前接口确实提供时用该模型。默认模型依当前 video-gen 指引，不写永久排名；同一个角色同一种风格优先固定主模型，只在失败或明确优势时换，换后做连续性检查。不同入口套餐和 API 额度不能默认通用。

Higgsfield / LTX 可作为用户点名或主路线受阻时的备选，但必须先发现真实工具或可操作界面、核验登录与能力，不从营销文案推断接口存在。本包不安装它们，也不自动迁移用户数据。GitHub 项目只吸收工作流思想，不运行未经审查的下载脚本。

## 异步与交付

依当前 schema 保存 generation jobId、outputAssetId、timelineId、renderId。生成跟踪与导出跟踪分别处理。超时不等于任务失败；重试前先确认原任务最终状态。不得从工具说明中的示例 ID 拼出请求。

付费模型版本、分辨率、单次时长、价格与会员资格在运行时核验。找不到价格或剩余额度时先保留未知值并完成文本方案；不得把公开 API 价当作 ChatCut 实际扣费。
